# 프로젝트 문서 안내

- **문서 버전:** v1.0
- **배포일:** 2026-10-17
- **문서 상태:** 정식 배포 · 개발 기준선

스미싱 예방 교육 및 탐지 시스템의 요구사항부터 테스트까지 관리한다. v1.0은 문서 정식 배포이며 서비스 출시·팀 전체 승인·실제 성능 검증 완료를 뜻하지 않는다.

## 문서별 기준

1. [01 기능 명세서](docs/01_Feature_Specification.md): 기능 ID, MVP·2차·도전 범위, 수익 모델, 개인정보 원칙.
2. [02 사용자 흐름](docs/02_User_Flow.md): 화면 ID, 경로, 사용자 행동과 복구 흐름.
3. [03 시스템 아키텍처](docs/03_System_Architecture.md): FE·BE 책임, 기술 스택, 분석·배포 구조.
4. [04 DB 설계서](docs/04_Database_Design.md): 테이블, 제약, 콘텐츠 버전, 저장·백업 정책.
5. [05 API 명세서](docs/05_API_Specification.md): 입력 제한, 응답·오류 코드, 시간·요청 제한.
6. [06 UI 설계서](docs/06_UI_Design.md): 화면 배치, 표시 순서, 접근성, 상태 처리.
7. [07 테스트 계획서](docs/07_Test_Plan.md): 검증 시나리오, 담당, 성능 평가와 인수 기준.

중복 설명이 다르면 해당 주제의 기준 문서에서 먼저 수정하고 연관 문서를 함께 갱신한다. 기능 범위는 01, 데이터는 04, 통신 수치·코드는 05가 기준이다. UI와 테스트가 이 기준을 임의로 바꾸지 않는다.

## 공통 개발 기준

- MVP: 비회원 URL·문자·QR 검사, 공통 결과, 공개 교육과 퀴즈.
- 2차: 회원·학습 기록·선택 저장 요약, 기관 교육 관리, OCR·결과 내보내기·피드백·콘텐츠 및 규칙 관리.
- 도전: 동적 페이지 분석, 조작 이미지 판별, 서비스 운영 통계.
- 분석: 규칙 기반이며 대상 URL 접속·DNS 조회·리디렉션 추적을 하지 않는다. 외부 평판은 기본 비활성인 선택 연동이다.
- 점수: 0~29 안전, 30~59 주의, 60~100 위험. 확인된 치명 규칙은 최종 위험 등급을 적용한다.
- URL: 공백 제거 후 최대 2,048 Unicode code point. 문자: 원본 기준 최대 5,000 code point, 중복 제거 URL 최대 5개.
- QR: 파일 1개, PNG/JPG/JPEG, 최대 10,000,000 bytes, 각 축 4,096px. 전체 요청은 11,000,000 bytes 이하.
- 시간: 분석 BE 15초·FE 30초, 외부 평판 개별 3초. 교육·퀴즈 BE 5초·FE 10초.
- 요청 제한: IP별 고정 60초 구간, 분석 합산 20회·교육 및 퀴즈 합산 60회.
- DB: OCI Docker PostgreSQL에 교육·퀴즈 콘텐츠만 저장한다. MVP 검사 원문·결과·퀴즈 제출은 저장하지 않는다.
- 콘텐츠: 7개 유형별 사례 최소 1개, 퀴즈 세트당 10문제. 이전 공개 세트는 MVP 운영 기간 동안 보존한다.
- 임시 파일: 정상 처리 후 즉시, 실패·중단 시에도 업로드 후 10분 이내 삭제한다.
- 백업: 하루 1회, 최근 7일 보관. 분리된 DB에서 복원 검증한다.

## 미확정 항목

다음 항목은 v1.0의 기능 범위를 바꾸지 않는 구현·검증 후속 작업이다.

- 탐지 규칙별 조건·배점, 규칙 버전과 데이터셋 라벨.
- 최종 평가 전에 확정할 탐지율·오탐률·성능 목표.
- 라이브러리·PostgreSQL 이미지 버전, ORM·마이그레이션 도구, 서버 자원과 배포 주소.
- 외부 평판 제공자와 전송 정책. 승인 전에는 비활성 상태로 검증한다.
- 서비스명·로고, 실제 접근성 검증에 따른 시각 조정.
- 2차 인증·기관 권한, 최소 집계 인원, 보관·삭제 정책, 요금제와 계약.

## 버전과 변경 관리

문서 버전 v1.0, API 경로 v1, 규칙 버전과 퀴즈 버전은 서로 독립적이다. 문서 배포만으로 API 경로나 예시 규칙 버전을 변경하지 않는다.

변경 시 영향받는 기능·화면·데이터·API·UI·테스트를 같은 변경 단위로 검토하고 조직 소개도 함께 갱신한다. 구현 결과는 각 저장소의 PR과 테스트 실행 기록으로 확인한다.

## v1.0 정리 내역

- 01~07과 조직 안내·협업 가이드의 문서 버전과 상태 통일.
- 선택 저장 요약(F-301)과 개인 기록 관리(F-311)의 역할·2차 범위 통일.
- 부분 결과 우선 표시, 비URL QR, 외부 평판 비활성·실패 구분 통일.
- 분석·교육·퀴즈별 시간 제한과 테스트 기대 오류 정합성 정리.
- 공개 퀴즈 버전 채점 정책, 검사 결과·퀴즈의 교육 연결 방식 정리.
- 기관 이수 상태와 집계 통계의 접근 범위 및 개인 검사 정보 비공개 원칙 통일.
- 최종 평가 데이터 분리와 목표 확정·인수 조건 명시.
